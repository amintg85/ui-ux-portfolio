# Product Interface Design Portfolio — Concept Projects

Three original, responsive frontend concept demos:

1. **Northstar Analytics Dashboard** — KPI cards, navigation, and a revenue trend visualization.
2. **Atlas AI Assistant** — document Q&A chat interface concept, with a local-only demo interaction (no AI backend).
3. **MarketFlow Commerce Admin** — orders, status labels, and sample commerce metrics.

## Run
Open `index.html` in a browser. No installation or dependencies required.

## Publish as a portfolio link
Create a GitHub repository, upload `index.html` and `README.md`, then enable GitHub Pages under **Settings → Pages → Deploy from a branch → main / root**. Use the Pages URL in your application after verifying it works.

## Disclosure
These are original fictional demonstration projects with sample data, not client deliverables. They were implemented using HTML, CSS, and JavaScript, not Figma, Canva, or Adobe products.
